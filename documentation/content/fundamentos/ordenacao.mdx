---
title: Ordenação
description: Ordem padrão de cada listagem e onde ela pode ser alterada.
---

| Endpoint | Ordem | Configurável |
| --- | --- | --- |
| `GET /animals` | Mais recentes primeiro (`createdAt` desc) | Não |
| `GET /users` | Mais recentes primeiro | Não |
| `GET /monitoring`, `/monitoring/mine` | Mais recentes primeiro | Não |
| `GET /events`, `/admin/events` | `startsAt` ascendente | Sim: `order=asc` ou `order=desc` |
| `GET /events/categories` | Nome (A–Z) | Não |
| `GET /configs` | Chave (A–Z) | Não |
| `GET /admin/audit-logs` | Mais recentes primeiro | Não |

Para mostrar o histórico de eventos do mais recente ao mais antigo:

```bash
curl "https://apasbac-api.vercel.app/api/v1/events?when=past&order=desc"
```
