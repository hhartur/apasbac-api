## Rodando a API localmente

```bash
git clone https://github.com/hhartur/apasbac-api.git
cd apasbac-api
cp .env.example .env          # ajuste DATABASE_URL e os segredos JWT
npm install
npx prisma migrate deploy
npm run prisma:seed           # cria admin local, configs e categorias de eventos
npm run start:dev
```

<Callout type="warning" title="Credenciais do ambiente local">
Fora de produção o seed cria `admin@apasbac.org.br` com uma senha padrão de desenvolvimento. Em produção não existe senha padrão: o primeiro admin só é criado se `SEED_ADMIN_PASSWORD` for definido.
</Callout>
