- Repositório da API e desta documentação: [github.com/hhartur/apasbac-api](https://github.com/hhartur/apasbac-api)
- Pasta da documentação: `documentation/`
- Especificação: `documentation/openapi/openapi.json` (gerada por `npm run openapi:export`)

## Reportar problemas

Abra uma [issue](https://github.com/hhartur/apasbac-api/issues/new) com método, rota, status, `requestId` e o que era esperado.

<Callout type="security" title="Vulnerabilidades">
Não abra issues públicas para falhas de segurança. Entre em contato com a administração da APASBAC de forma privada.
</Callout>
